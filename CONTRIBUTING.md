# Guía de contribución

## Introducción

En esta parte voy a explicar cómo se pueden hacer cambios en mi proyecto sin dañar lo que ya está funcionando.

## Cómo trabajar con el proyecto

Lo primero es descargar el proyecto desde GitHub y abrirlo en Visual Studio Code. Después hay que instalar lo necesario con `npm install` para poder trabajar con la aplicación.

Antes de modificar algo, es bueno ejecutar `npm test` para comprobar que todo esté funcionando bien.

## Agregar nuevas funciones

Cuando quiera agregar algo nuevo a la aplicación, tengo que modificar el código y hacer pruebas para ver si funciona como esperaba.

Por ejemplo, en esta práctica agregué la opción de eliminar tareas y también hice cuatro pruebas nuevas para comprobar que funcionara correctamente.

## Revisar los cambios

Después de hacer cualquier modificación, ejecuto las pruebas para asegurarme de que no haya errores. Si todo sale bien, guardo los cambios y los subo a GitHub.

## Subir cambios al proyecto

Para subir los cambios utilizo Git. También se pueden crear ramas para trabajar en nuevas funciones sin modificar directamente la versión principal.

Cuando los cambios se suben a la rama principal, GitHub Actions comienza a revisar el proyecto automáticamente.

## Conclusión

Con esta práctica aprendí que es importante revisar los cambios antes de subirlos, porque un pequeño error puede hacer que las pruebas fallen. Por eso, siempre es mejor comprobar que todo funcione bien antes de publicar una nueva versión.
